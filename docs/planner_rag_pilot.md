# 联合 Planner 有/无知识对照

这是 12 条人工编写的受控请求、每条两组、各重复 3 次的机制实验，最多 72 次模型调用。每城 4 条，覆盖兴趣、当前票价名额未知、候选不足、空候选。不是随机真实用户分布，也不是原冻结测试集。

候选实体来自已有官方快照；南京博物院、上海博物馆东馆不在当前真实 POI fixture 内，所以这里只提供官方名称，不编造坐标、营业时间或票价。无法据此评估真实道路距离或完整旅行可行性。

两组使用实际 `make_joint_planner_node` 提示词构造与输出后处理；相同请求、候选、模型、温度、JSON schema，唯一消息差异是知识片段。取证固定为关键词检索，不代表生产 Chroma/BGE 效果。运行器直接采用 JSON mode 并作 Pydantic 校验，不使用生产结构化客户端的重试封装；因此结果不能称为生产端到端效果。串行调用、无重试、无地图、无 Reviewer/Judge；轮次交替两组顺序。

## 先检查预估

```powershell
python scripts/compare_planner_rag.py --out data/evaluation/planner_rag_preflight.json
```

会保存 12 条输入、24 份真实规划提示词、证据与配置指纹，不调用模型。未指定单价时费用为 null，而非免费；Token 上界按 UTF-8 字节加每次 256 开销保守估算，不是 tokenizer 实测或账单。确认模型和其当前每百万输入/输出单价后，加 `--model`、`--url`、`--input-price`、`--output-price` 再预估，输出使用新文件。

确认预算后才执行：相同参数加 `--execute --max-calls 72 --max-cost <已确认预算>`，并在 `RAG_GENERATOR_API_KEY` 环境变量设置密钥。脚本不会加载或打印本地密钥文件，不会覆盖旧报告。运行结果默认放在不提交的 `data/`。

## 怎么评判

自动检查只覆盖候选池、时间块结构、重复与非空路线，不能替代事实或偏好评价。空候选下正确拒答可能没有路线，应人工按拒答评价，不能将它计成有效行程。报告中的 basic rule pass 因此不是最终质量通过率。

逐请求保存完整输出、原始回复、失败原因、供应商实际 input/output Token、包含失败调用的耗时。缺失 Token 不补估算；总体可用率与基本规则率以全部预期调用为分母。P50/P95 是这轮 Planner 调用（含失败）的耗时，不是线上 SLA。未运行指标为 null。

人工逐对核查：事实能否由官方证据支持；未知票价/名额是否明确待确认；选点依据是否匹配兴趣；候选不足是否说明且不编造。填写 `human_scores` 并记录审核者与原因后才能归纳质量结论；AI 可辅助分析，但不能填成人工确认。不要只看 notes：检查 route JSON 是否真的对应其解释。

此轮的目的先发现 RAG 是否提供实质信息、是否诱发无依据事实。若知识始终只被原样抄进 notes，不能声称改善规划。真实道路信息、真实 POI 回放、更多未见样例、独立 Judge 与正式冻结评测应另做后续实验。

首轮离线预检（2026-10-08）：12 条有知识组请求仅 5 条取得证据，包含非空候选下的检索未命中。“三亚活动组成”兴趣请求未命中。保留这些情况作为诊断，不为保证结果而降低阈值；证据存在也不等于证据相关。默认预估 72 次调用、输入上界约 43 万 Token、输出上界 147456 Token；这不是实际用量。价格未确认，费用留空，未执行真实模型生成。

## 2026-10-08 真实调用进展

用户授权自行选择合理预算后，先按 DeepSeek 官方峰时价预估 0.306 美元、预算 0.50 美元。官方端点连续 3 次返回 401，因此停止，没有生成结果。价格依据：https://api-docs.deepseek.com/quick_start/pricing 。

改用项目当前配置的 `grok-4.6` / micu 网关。其公开 `/api/ratio_config` 返回模型倍率 1、输出倍率 3，`/api/status` 返回每显示货币单位 500000 配额、显示 CNY。按基础倍率换算输入 2、输出 6 元/百万 Token，未核实账户组倍率，因此它只是预算代理价，不是最终账单。每次调用前核查密钥范围的 `total_used`，最终费用应按配额变化并核实账户计价。

初次聊天接口生成未显式设置 low reasoning，2 条已记录回复耗时约 66/59 秒，首条输出 2806 Token，其中 2479 为思考 Token，超过所请求的 2048 输出上限。该尝试中断，可能还有未记录的在途请求；不并入正式对照，也不能声称精确合计收费。由此补充中断与在途记录，后续配置绑定 `responses_api` 与 `reasoning_effort`。

低思考组采用 Responses API、`reasoning_effort=low`，缩至 12 条请求各一轮，共计划 24 次，预算代理上限 1 元、网关配额上限 500000。已完成 **11 次、5 对完整配对**；用量监测接口持续 429，退避并等待后仍不可用，因此暂停，保留全部结果。不是模型超时或 13 次模型失败。续跑时相同配置加 `--resume`，只跑未完成项；有未决在途请求则拒绝自动续跑。
