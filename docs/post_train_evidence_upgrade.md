开放元数据来自9月已有高德POI快照，并未新增官方实时运营核验。道路矩阵只证明固定驾车耗时，不能证明停车/排队/缆车/预约/未来交通；丽江涉及玉龙雪山等景点不能称现场全链路可执行。测试只衡量固定输入约束的城市留出泛化。两个城市、每城共享候选的12个场景相关，不能当24个独立城市；结果应分城市展示，不能凭小样本大幅宣称提升。

## 如何使用与判断效果

评测脚本新增--cases和--maps，强制test-only状态、完整有向道路和可行解复检，校验冻结哈希。留出结果写入独立city-heldout-v1目录及docs/post_train_heldout_report.md，保护已记录60场景API指标，不混算。示例：

```powershell
python scripts/evaluate_post_train_ablation.py --model-name Qwen2.5-7B-Instruct --tag base --cases data/post_train/heldout_evidence_v1/cases.json --maps data/post_train/heldout_evidence_v1/maps.json --mode planner-only
```

四组统一测试：首轮JSON解析率、完整约束通过率、必去/排斥满足率、开放/通勤错误率；Rules+Rework再看完整成功率与返工/耗时/token。偏好验证看chosen胜率及margin，同时必须看完整路线业务通过率，不能只看DPO loss。人工负例训练主要覆盖硬规则，软约束收益需单列，不能外推。模型比较逐场景配对，展示成功/失败原始计数；同源60场景与城市留出24场景分表。当前尚未进行新一轮模型指标评测，所有模型收益待测。
