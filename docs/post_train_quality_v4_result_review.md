# v4结果复核：未达到替代v2的条件

两组48步SFT和300次本地评测全部完成，Base服务已恢复并验证。训练与本地评测阶段没有新增付费调用；之前合成48条数据使用53次教师调用、314478 Token。两组训练与合并合计28.2分钟，自动评测完成状态已落盘。

|---|---:|---:|---:|---:|---:|

冻结指标表面显示v4共同通过增加9次，但本轮复核发现新的解释漏检，因此不能按这个指标宣布成功或部署v4。

## 解释模板迁移了错误形式，没有解决数值一致性

旧检查器识别reasoning/notes中的“每个景点N分钟”等表述，没有检查每条selection_reasons中的“安排N分钟”。v4大量生成新训练模板，但时刻表变成90或120分钟时，理由仍写“安排60分钟”。上海2-01、种子42，两个景点均排90分钟，理由却均写60分钟；该路线原规则通过。

在保留冻结成绩的前提下，对三个模型统一增加一个事后窄诊断：选点理由中明确的“安排/参观/停留N分钟”是否等于该景点实际时间差。仅比较确切数字，不处理约数或上下界，也不是完整语义评价。结果：

|版本|新诊断发现问题的生成记录|其中原规则通过|原规则＋原解释检查＋新诊断共同通过|
|---|---:|---:|---:|
|v2|0|0|99/150|
|v4_clean|25|18|75/150|
|v4|40|25|83/150|

v2在这个新窄模式下未命中，不等于不存在其他语义问题；v2原有23条时长问题仍由旧检查记录。新诊断为事后分析，不能替换冻结主指标、挑选性只惩罚某个模型或宣称是穷尽语义正确率。

本次确定性改写的训练目标本身按时间表计算分钟数，没有已知数字冲突；生成仍错误，说明正确数字模板不保证模型学会随时间重新计算。与模板化输出行为一致，但未进行独立因果消融，不能将全部退步归因于模板。

## 补数有局部收益，但路线和无解能力仍不足

v4相对清洗组规则93→108（+10个百分点），按题分层配对bootstrap区间约[0.7,20.0]，支持这批补数在本设计集有局部收益。实际监督Token分别271700与268808，接近；输入Token1474124与1576604，样本曝光736与744条次，均非独立样本数。固定48步不代表数据曝光等价。

相对v2，v4常规99→96；困难20→12。其中无解7→0是关键退步：所有15次均仍生成路线，包括候选数量不足，以及只能正午参观却没有明确室内证据。新增3条拒绝样本仅覆盖3候选需4个的两日数量无解，没有覆盖天气资格为空等不同机制；3条也不能证明已学会拒绝。这是分布覆盖缺口，不应以开发原题补答案。

v4较v2：午休12→15，高温边界8→10，候选名称别名越界3→0；但开放时间失败7→13、必去缺失2→7、通勤冲突1→6。错误项可能重叠，不可相加当独立失败数。有解135次中v2通过112、v4通过108，表明不只是无解题拖低成绩。

## 下一步建议

1. 保留v2作参考，v4保留为诊断模型，暂缓DPO或下一轮大批补数。本轮原计划中的“解释改写后整体更可信”假设未得到支持，需要纠正。
2. 先以0模型调用完成统一解释审计：覆盖选点理由、天数、总数、时长、无解说明及未知属性；原冻结分数保持，扩展诊断单列，加入真实失败回归。不能把绕过窄检查器当进步。
3. 优先考虑删除不必要的重复数字，让模型给出约束依据；面向用户的分钟数、点数由程序根据最终时间表生成。若保留模型算术，应单独验算而非依赖模板学习。此为建议，尚未修改生产输出协议。
4. 历史隔离66条、协议迁移、解释全面改写同时发生，不能声称单纯“清洗坏数据”造成退步。下一轮先隔离因素：固定同一批输入与目标路线，只改变解释策略，记录训练Token预算；大候选池与针对性补数效果另作对照。
5. 无解数据需覆盖数量、时间/开放不可行、天气资格为空，并配匹配的可行邻例；控制比例、评测可行题误拒绝。需要付费生成前先明确调用数与预算，不默认再次补数。

证据均来自开发集、单训练种子；3个推理种子不能替代多次训练。独立测试、API教师同协议对照和返工闭环本轮尚未执行。下一轮如需实施，应先把上述免费诊断和具体对照设计做成可审阅结果。
