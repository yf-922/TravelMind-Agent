## 数据调整分析方法

1. 先比较Base与各SFT，按常规、困难、可行、无解、城市、约束类型拆分；不能用可行题空排取得表面高分。
2. 用逐题配对找SFT相对Base新增失败，与所有模型共同失败分开。按案例聚合三个种子，并给出分层配对bootstrap区间；区间仅条件于此设计开发集。
3. 对具体错误先核查输入事实、评分规则、输出格式、路线与解释。JSON可解析仍可能有不符合HH:MM协议的完整日期时间，属于输出协议问题；它与HTTP/超时应分开分析。
4. 对确需数据修复的类别给出清洗或增量方向，禁止把评测题、见证、同题改写复制进训练。联合输入输出长度须审计，不能为扩大候选池而截断监督答案。
5. 原模型先保留，不自动DPO/续训。常规样本为主但训练配比不机械照抄评测80/20；按混合、曝光和训练步数做受控增量对照。

正式版本的最终成绩及建议须等待完整运行；任何中途数量不构成排名。Smoke不参与正式版本选择。
