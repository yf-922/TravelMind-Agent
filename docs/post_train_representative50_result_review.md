## 失败事实及含义

1. **解释和时间表脱节。** v2有23次被现有解释检查标记，其中20次路线规则本来通过，导致119降至99。南京案例1-08、种子42，两个景点各排120分钟，却写“每个游览60分钟”；上海2-07、种子42，一日两景却称“两天、每天各一个”，通勤缓冲叙述也与时间不符。后者还说明现有检查会漏掉语义问题。
2. **不能诚实处理数量无解。** v2在“仅2个可用景点，要求恰好3个不同景点”的9次生成中仅正确处理1次；高温时段没有明确室内候选的6次则全部正确处理。南京1-10、种子42，列出2个景点仍宣称“恰好3个”。应区分数量恰好、最多、可退让，以及明确要求无解时返回空计划的任务。
3. **联合约束仍会漏。** v2有7次开放时间相关失败、3次高温、3次午休冲突，计数可以重叠，不能相加当作独立失败数。上海2-06、种子42，景点16点关闭仍排15–17点；成都4-06、种子42，称避开11–15点却排14点开始。
4. **候选精确引用。** 上海2-02的3个种子用了“上海博物馆”，输入实际是“上海博物馆(人民广场馆)”。这是未验证别名，不宜描述成凭空编造景点，也不能直接放宽越界检查。
5. **未知属性不能靠名称推断。** 人工确认一条苏州数量无解输出把indoor=None的候选称为“唯一室内景点”。正则筛查还有否定句误报，不能将筛查数量当作真实错误率。

新的大候选池下，v2没有景点重复失败，多日不同数量分配15/15通过。说明重复不是当前首要瓶颈；不能据此证明历史重复完全由候选池小造成，因为题目、约束与资产同时变化。历史训练候选数1–8，新常规测试19–24，确有分布差异，但没有单变量因果实验。

v3和MC均未超越v2，不能简单归咎27条补数。协议迁移、数据清理、样本曝光等同时变化；本轮只有推理重复，没有多次训练重复。
