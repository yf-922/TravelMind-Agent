# 扩池教师从零规划：10 例试跑结果

本次仅改训练数据构造，不改冻结测试集、生产规划逻辑或 v2 权重。教师未获得历史答案、路线、旧选点建议或评测见证。首轮生产消息逐条重捕获核对一致；返工仅使用本次教师自己的新草稿。

## 输入与调用

- v2 母本 250 条；每条扩为 15 个真实同城候选，原候选保留。
- 236 条可调用，14 条隔离：13 条室内强要求缺可靠范围证据，1 条缺真实步行道路。成都、苏州另有 8 条使用既存官方材料恢复馆内展厅的范围标注。隔离改变天气分布，不宣称与 v2 数据分布完全一致。
- 训练专用检索保留上海、三亚原始 POI 响应；共保存 3,316 条有向驾车道路、131 次道路批量请求。道路快照不证明停车、船班或未来交通状态。
- 五城市各两例，覆盖常规多日、高温、雨天及必去/排除约束。没有调用 LLM Reviewer。
- 实际教师调用 11 次，累计全局 627 次，上限 1000；本轮付费调用已停止。

两个失败响应分别带有 JSON 外文本，其中一个 reasoning 为列表而非字符串。保留原始响应并按失败记账，没有抽 JSON、改类型或拼接答案后算作成功。两条失败分别报告 52,996、56,668 总 Token，占本轮报告用量约 61.9%；其输入用量为 51,188、50,575，明显高于其余请求报告值。现有记录不足以确定代理内部发生了什么，不能推测隐藏调用、账单价格或将本地 Qwen 长度当成代理计费依据。

成都雨天样本首轮编造 source_ids，被本地审计驳回；一次返工后清除引用，保留有来源支持的馆内范围，不使用旧教师答案。

## 不能跳过的质量问题

规则通过还不能等于“所有解释事实可信”。逐条审阅发现上海一例将东馆等多个点统称陆家嘴片区，输入地址分别是世纪大道与陆家嘴环路，细分片区归属没有输入证据。三亚一例选西岛：已有驾车道路不证明渡船班次、末班船或进出岛可行性。两例额外标记复核，未发布为可训练数据。

三日路线达到 3,513、3,488 Token，已接近 3,584 上限。当前十例没有超长，不代表全量不会超长。不能自动截掉答案结尾，也不能静默把候选减少到 15 以下。

结论：扩池输入和从零规划流程已跑通；本轮不足以放行全量生成和训练，更不能据此判断新 SFT 优于 v2。当前没有训练任务，也没有启动 DPO。

## 下一步

1. 用已保存的请求/响应核查代理 JSON Schema 遵循性与用量计量，优先零新增调用分析；必要的接口小试仍占现有预算。
2. 补解释事实证据门槛与海岛交通限制，不能把地理细分断言或驾车结果当成全部证据。保持原始教师答案，失败则隔离或教师返工，不用模板改写掩盖问题。
3. 确定完整序列长度策略；再次小试验证后才恢复全量。按本轮用量机械外推 236 条约 418 万报告 Token，但异常计量未解释，这不是可靠成本承诺。
4. 数据审计和发布通过后，再做 GPU0 显存冒烟、SFT、冻结 50 题三推理种子配对评测。训练前不作效果提升承诺。

验证：最终完整 pytest 为 615 passed，3 个既存警告。原始账本、调用响应、输入隔离明细与二次审阅均位于 `data/post_train/v2_large_pool_teacher_v1/`。
