# 第二批开发集审核：10 条查询、7 个意图组

状态：AI 建议，待用户决定范围及人工确认证据。仅开发集，不修改原问题或标签，不参考检索排名。以下按意图组审核，同义问法一起处理。缺事实不等于整条拒答，已知部分可在说明边界后回答。

## 1. 上海博物馆亲子注意事项（2 条）

案例：`v2-1-3-0`、`v2-1-3-1`。第二条含“不要用重庆攻略”的跨城市干扰。

现有有效证据：上海博物馆预约页写明“古代文明探索宫、数字馆仍需提前预约”，通过官方微信小程序东馆“专项预约”办理。原标签是已结束、适龄 18–100 岁的讲座，不能作为亲子注意事项。

来源：https://reservation.shanghaimuseum.net/

建议：保留题，补适用馆区、儿童年龄、成人陪同条件的官方语料；补完之前标为缺关键事实，不猜儿童资格。

请答：同意补语料 / 只问专项预约（另建题并保留原题） / 待确认。

## 2. 上海博物馆雨天注意事项（1 条）

案例：`v2-1-5-0`。

当前没有充分的雨天入口、室外排队或避雨路径证据，旧讲座也不支持此问题。带伞等一般建议可生成，但不证明 RAG 找到了场馆事实。

建议：保留为缺事实案例；如果新增一般雨天建议，明确它是建议，不是官方设施保证。涉及到达路径的部分归地图工具链路。

请答：保留缺事实题 / 补一般建议并区分官方事实 / 退出 RAG 范围 / 待确认。

## 3. 上海旅行安全提醒（1 条）

案例：`v2-1-7-0`。

现有证据仅涉及上海博物馆团队入馆：学生团队须签安全责任书，团队服从场馆管理、维护文物安全。这不能代表整个上海的旅游安全。

来源：https://www.shanghaimuseum.cn/mu/frontend/pg/infomation/team-reservation

建议：保留为澄清案例，先询问活动区域与场景；不直接把团队规定套给普通散客。

请答：同意先澄清 / 待确认。

## 4. 上海博物馆慢游路线（1 条）

案例：`v2-1-9-0`。

现有语料只有文创商店地址和营业时间，没有展厅动线、停留时长与休息点；商店时间也不能当展馆时间。原来的两个讲座不是路线证据。

来源：https://www.shanghaimuseum.cn/mu/frontend/pg/service/shop

建议：先确认馆区、兴趣和体力。保留知识不足案例，补馆内导览或一般慢游建议；不承诺语料中不存在的具体休息点。地图 API 也不必然提供馆内展厅动线。

请答：补导览语料 / 只给一般慢游建议并说明边界 / 待确认。

## 5. 重庆中国三峡博物馆预约（2 条）

案例：`v2-2-0-0`、`v2-2-0-1`。

证据原文：“自10月1日起实行免预约进馆，观众凭有效身份证件即可有序入馆。其中，重庆宋庆龄纪念馆、重庆白鹤梁水下博物馆需购票进入。”截取块没有年份。

来源：https://www.3gmuseum.cn/web/article/1430010139317059584/web/content_1430010139317059584.html

建议：保留题，核实公告年份及当前适用性后，再作为当前预约政策标注。此次只核对已保存文本，尚未实时核实该重庆公告。

请答：同意保留并核实有效期 / 待确认。不要仅凭这段确认当前免预约。

## 6. 重庆轨道交通到达与换乘（2 条）

案例：`v2-2-2-0`、`v2-2-2-1`。

问题没有起终点；语料讲老人免票和换乘票价优惠，不是站点路径。票价优惠不能替代导航。

来源：https://www.cqmetro.cn/yyfw/pwzc/

建议：退出静态 RAG 检索范围，作为“先询问起终点，再调用地图”的工具路由案例保存。与你此前南京交通题的决定一致，但此次仍需你确认范围。

请答：同意交地图链路 / 保留为澄清案例 / 待确认。

## 7. 重庆旅行购票与入场条件（1 条）

案例：`v2-2-6-0`。

“重庆旅行”没有统一票价或入场要求，原标签的游船票价不能推广到整个城市。

建议：保留为澄清案例，先问具体景点或产品，不静默改成三峡博物馆。

请答：同意先澄清 / 待确认。
