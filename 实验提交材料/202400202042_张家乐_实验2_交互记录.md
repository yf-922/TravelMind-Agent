# 实验2交互记录（整理版）

| 轮次 | 讨论/问题 | 设计决定 |
|---|---|---|
| 1 | 当前工作流是不是动态调度？ | 主链路是固定顺序；Reviewer 未通过和 Worker 失败时使用条件路由，属于有限动态调整。 |
| 2 | WorkAgent 是什么？ | 指承担具体子任务的 Worker Agent；本项目对应 Intent、POI、Planner、Reviewer。 |
| 3 | 所有 Agent 是否共享一份记忆？ | 否。共享任务消息，私有 memory 按 `session_id + agent_name` 隔离。 |
| 4 | Chroma/向量库是否等同记忆？ | 否。向量库用于语义检索；Agent 工作记忆和用户画像是不同层次的数据。 |
| 5（模拟） | 消息为什么还要 task_id 和 trace_id？ | 用于把一次请求的多次分发、重试、结果关联起来，方便审计和排错。 |
