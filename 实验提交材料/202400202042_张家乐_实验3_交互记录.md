# 实验3交互记录（整理版）

| 轮次 | 问题/操作 | 结果 |
|---|---|---|
| 1 | 检查“各 Agent 独立记忆是否真的做了” | 采用独立 Agent 实例 + SQLite `session_id, agent_name` 隔离，并写入自动化测试。 |
| 2 | 检查 Supervisor 能否按调度逻辑分发 | 日志依次出现 intent、poi、planner、reviewer；Reviewer 失败可返工一次。 |
| 3 | 检查不同 Agent 是否能调用不同工具 | ToolRegistry 对未授权 Agent 抛出 ToolPermissionError。 |
| 4 | 某个 Agent 失败会不会整体崩溃 | 模拟 IntentAgent 超时，Supervisor 重试两次后返回结构化失败结果。 |
| 5 | 如何证明不是切换 prompt 的伪多 Agent | 分别打印各实例的 prompt、memory 和工具权限；测试确认内存内容不同。 |
| 6（模拟） | 如果 POI 工具无结果怎么办？ | 返回空候选池和结构化失败/降级提示，不让 Planner 自行虚构地点。 |
