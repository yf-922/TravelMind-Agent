## 2. 可运行核心代码摘录

### 2.1 独立 Agent 提示与私有记忆：`app/multi_agent_core/agents.py`

```python
class BaseAgent(ABC):
    """Each instance owns its prompt and memory. No global message list is used."""

    def __init__(self, name, system_prompt, *, model=None,
                 allowed_tools=None, memory_store=None):
        self.name = name
        self.system_prompt = system_prompt
        self.private_memory = []
        self.memory_store = memory_store or InMemoryAgentMemoryStore()
        self.model = model
        self.allowed_tools = frozenset(allowed_tools or set())

    def _activate_memory(self, message):
        session_id = message.session_id or message.task_id
        self.private_memory = self.memory_store.load(session_id, self.name)
        return session_id
```

每个 Agent 实例各自持有 `system_prompt` 与 `private_memory`。记忆读取时以 `session_id + agent_name` 为键；没有全局 `messages` 列表供所有 Agent 共用。

### 2.2 Supervisor 集中调度与失败重试：`app/multi_agent_core/supervisor.py`

```python
def route_after(self, result, *, review_passed=None):
    if result.status == "failed":
        return "stop"
    if result.task_type == "intent_extract":
        return "poi_research_agent"
    if result.task_type == "poi_research":
        return "planner_agent"
    if result.task_type == "itinerary_plan":
        return "reviewer_agent"
    if result.task_type == "itinerary_review":
        return "done" if review_passed else "planner_agent"
    return "stop"

for current_attempt in range(attempt, self.max_attempts):
    try:
        result = agent.run(message)
        self.dispatch_log.append(result)
        return result
    except Exception as exc:
        if current_attempt + 1 >= self.max_attempts:
            return failed_message(error_code=type(exc).__name__)
```

该逻辑体现“集中式调度”：Worker 只完成自己的任务，只有 Supervisor 决定下一位 Worker；Worker 异常时最多重试 `max_attempts` 次，再返回结构化失败结果。

### 2.3 POI 工具权限：`app/multi_agent_core/agents.py`

```python
class POIResearchAgent(BaseAgent):
    def __init__(self, tool, *, model=None, memory_store=None):
        super().__init__(
            "poi_research_agent",
            "Verify travel places with the POI tool.",
            model=model,
            allowed_tools={"poi_search"},
            memory_store=memory_store,
        )

    def use_poi_tool(self, city, query=""):
        if "poi_search" not in self.allowed_tools:
            raise PermissionError(f"{self.name} cannot use poi_search")
        return self.tool.search(city, query)
```

## 3. 已实现能力

1. Supervisor 依次分发 `intent_extract`、`poi_research`、`itinerary_plan`、`itinerary_review`。
2. Reviewer 不通过时，向 Planner 发出 `itinerary_revise`，再进行一次复审。
3. POIResearchAgent 具有 `poi_search` 工具权限；未授权 Agent 调用时抛出 `ToolPermissionError`。
4. 每个 Agent 使用独立私有 memory；SQLite 以 session 和 agent 双键隔离。
5. Worker 发生异常时 Supervisor 按 `max_attempts` 有限重试，并返回 `failed_agent/error_code`。
