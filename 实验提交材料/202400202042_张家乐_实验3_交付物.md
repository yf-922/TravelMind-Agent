- 核心目录：`app/multi_agent_core/`
- 调度器：`supervisor.py`
- Agent：`agents.py`（IntentAgent、POIResearchAgent、PlannerAgent、ReviewerAgent）
- 消息模型：`messages.py`
- 私有记忆：`memory.py`（SQLiteAgentMemoryStore）
- 工具权限：`tools.py`（ToolRegistry、FixturePoiTool、AmapPoiTool）

## 2. 已实现能力

1. Supervisor 依次分发 `intent_extract`、`poi_research`、`itinerary_plan`、`itinerary_review`。
2. Reviewer 不通过时，向 Planner 发出 `itinerary_revise`，再进行一次复审。
3. POIResearchAgent 具有 `poi_search` 工具权限；未授权 Agent 调用时抛出 `ToolPermissionError`。
4. 每个 Agent 使用独立私有 memory；SQLite 以 session 和 agent 双键隔离。
5. Worker 发生异常时 Supervisor 按 `max_attempts` 有限重试，并返回 `failed_agent/error_code`。

## 3. 端到端运行日志样例

```text
[dispatch] intent_extract  -> intent_agent      attempt=0
[result]   intent_agent    -> supervisor        status=done
[dispatch] poi_research   -> poi_research_agent attempt=0
[result]   poi_research_agent -> supervisor     status=done
[dispatch] itinerary_plan -> planner_agent     attempt=0
[dispatch] itinerary_review -> reviewer_agent  attempt=0
[result] review.approved=True；输出 itinerary 非空
```

## 4. 红线验证

- `test_sqlite_memory_is_isolated_by_session_and_agent`：验证不同 Agent / session 的 memory 互不读取。
- `test_tool_registry_rejects_cross_agent_tool_access`：验证工具权限不混用。
- `test_supervisor_routes_rejected_draft_back_to_planner_once`：验证条件返工而非死循环。
