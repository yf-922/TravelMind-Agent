# 实验3：核心实现（多智能体编排）实验报告

姓名：张家乐　学号：202400202042

## 一、实验目的

1. 掌握集中式调度的多智能体编排与实现。
2. 理解独立记忆、工具调用和调度协作的作用。
3. 完成一个可运行的多智能体核心。

## 二、实验内容

项目实现了四类 Worker Agent 和一个 Supervisor。IntentAgent 负责抽取意图，POIResearchAgent 使用 POI 工具形成候选池，PlannerAgent 基于候选池生成行程，ReviewerAgent 进行审核。系统同时接入了 FixturePoiTool 用于离线可复现测试，并预留 AmapPoiTool 对接真实 POI。

每个 Agent 是独立类实例，拥有自己的 `system_prompt`、`private_memory` 和允许工具集合；SQLiteAgentMemoryStore 以 session 和 agent 维度持久化。Supervisor 不读取 Worker 私有 memory，只保存调度日志并传递必要的结构化结果。

## 三、实验步骤

1. 定义 `AgentMessage`，统一任务类型、发送方、接收方、内容、状态和重试次数。
2. 实现 BaseAgent 的私有记忆追加逻辑，再分别实现四个专属角色。
3. 实现 Supervisor 的 `_dispatch`：记录日志、调用 Worker、捕获异常、有限重试。
4. 实现 `route_after`：审核通过后结束，审核失败后仅返工一次。
5. 接入 ToolRegistry，将 POI 查询权限只授予 POIResearchAgent。
6. 运行多 Agent 测试，打印 dispatch log 并检查各 memory 内容不同。

## 四、心得体会

本实验最大的收获是把“角色说明”落成了代码约束：独立实例保证 memory 不污染，工具注册表限制越权调用，Supervisor 的调度日志让协作过程可复核。实现中不能只看最终答案是否生成，还必须验证消息是否按预期流动、失败是否被控制在单个 Worker 内。
